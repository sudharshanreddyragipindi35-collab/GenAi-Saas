   execution checklist.

Implemented slice 1 - Local MVP backend and UI
Developed:
- FastAPI backend entrypoint in backend/app.py.
- Layered backend folders for api, core, schemas, and services.
- Health API: GET /api/health.
- Website draft API: POST /api/websites/generate.
- Deterministic website generator service.
- Static localhost UI served from backend/static.
- README run instructions.

How to test:
1. Run: python -m uvicorn backend.app:app --reload --host 127.0.0.1 --port 8000
2. Open: http://127.0.0.1:8000
3. Click Generate Draft.
4. Confirm the preview and JSON tabs update.
5. Open: http://127.0.0.1:8000/api/health
6. Confirm the response status is success.
